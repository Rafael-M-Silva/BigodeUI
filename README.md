# BigodeUI

Demonstração de componentes visuais da BigodeUI com HTML e CSS.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Página principal em `index.html`; estilos em `style.css`.

**Tecnologias:** `CSS`, `HTML`.

## Visualizar localmente

Use um servidor HTTP local para abrir `index.html`.
